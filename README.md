AI-powered Exploratory Data Analysis (EDA) tool that uses **Ollama LLMs** to automatically analyze CSV datasets and generate intelligent insights, summaries, and visualizations.

It removes the need for manual EDA by combining  **Python data analysis + local Large Language Models** , making data exploration faster, private, and cost-free.

The project combines traditional data analysis techniques with generative AI to simplify and accelerate the data exploration process. Instead of manually writing code for EDA, users can simply upload a dataset and receive automated statistical summaries, visual insights, and AI-generated explanations.

The system performs data cleaning, missing value handling, correlation analysis, and visualization generation using Python libraries such as Pandas, Matplotlib, and Seaborn. On top of this, a locally running LLM (via Ollama) interprets the dataset structure and produces human-readable insights, making the analysis more intuitive for both beginners and professionals.

This project is fully offline, ensuring privacy and eliminating dependency on external APIs, making it suitable for secure and cost-free data analysis workflows.

### Objective

To build an intelligent, local AI-based EDA tool that automates data exploration and provides instant insights from raw datasets.

### Key Highlights

* Automated data profiling and cleaning
* AI-generated insights using Ollama LLMs
* Visual analytics for better understanding of data
* Fully offline and privacy-focused architecture
* Simple upload-and-analyze workflow

### Outcome

Users can quickly understand dataset structure, detect patterns, identify issues, and gain insights without writing complex code, significantly reducing the time required for exploratory data analysis.
